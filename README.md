# تطبيق Royal Chat - دردشة صوتية وترفيه 🎤👑

**تطبيق دردشة صوتية ترفيهي متكامل مع واجهة عربية فخمة**

## 🌟 المميزات الرئيسية

### 1. **الغرف الصوتية المباشرة**
- غرف صوتية عامة وخاصة
- دعم عدة مستخدمين في نفس الوقت
- كتم الميكروفون وإزالة الصوت والرفع على المنصة
- محادثة نصية داخل الغرف
- إدارة متقدمة: قبول/رفض المستخدمين

### 2. **نظام الهدايا المتحركة**
- متجر هدايا افتراضي جذاب
- هدايا مدفوعة ومجانية
- تأثيرات بصرية احتفالية (تيجان، قلوب، ورود، سيارات، ألعاب نارية)
- سجل كامل للهدايا
- هدايا حظ بمكافآت عشوائية

### 3. **نظام العملات والمحفظة**
- محفظة افتراضية لكل مستخدم
- نظام شحن آمن (تطبيق فقط)
- سجل معاملات شامل
- حماية من التلاعب والاحتيال

### 4. **الألعاب الداخلية**
- ألعاب متعددة اللاعبين وفردية
- نظام نقاط وترتيب يومي/أسبوعي
- جوائز افتراضية
- غرف لعب جماعية

### 5. **نظام المستويات والرتب**
- ترقيات بناءً على النشاط والنقاط
- أوسمة وإطارات مميزة
- رتب خاصة للداعمين
- صفحة إنجازات

### 6. **الملفات الشخصية والأصدقاء**
- ملفات شخصية غنية بالمعلومات
- نظام الأصدقاء والرسائل الخاصة
- صور رمزية وإطارات مميزة
- إشعارات فورية

### 7. **لوحة الإدارة**
- إدارة الحسابات والغرف
- إدارة الهدايا والعملات
- إدارة المشرفين والصلاحيات
- مراجعة البلاغات والحظر
- سجلات كاملة للأنشطة

### 8. **دعم كامل للعربية (RTL)**
- واجهة محسّنة للعربية
- اتجاه الكتابة من اليمين إلى اليسار
- تواريخ وأوقات عربية
- رسائل وإشعارات عربية كاملة

## 📋 متطلبات النظام

### الخادم (Server):
- Node.js v18+
- MongoDB 5+
- Redis (اختياري للـ caching)
- PORT: 5000

### التطبيق الطويل الأمد:
- React Native CLI أو Expo
- Android Studio + Android SDK
- Xcode (لـ iOS)
- Java Development Kit (JDK)

### الخدمات الخارجية:
- **Twilio** أو **Agora** للاتصالات الصوتية (اختياري - يمكن استخدام WebRTC)
- **Firebase** للتنبيهات (اختياري)
- **Stripe** أو نظام دفع آخر (اختياري - التطبيق الحالي محاكاة فقط)

## 🚀 البدء السريع

### 1. تثبيت الخادم

```bash
cd backend
npm install
```

### 2. تكوين متغيرات البيئة

إنشاء ملف `.env` في مجلد `backend`:

```env
PORT=5000
MONGODB_URI=mongodb://localhost:27017/royal-chat
JWT_SECRET=your_secret_key_here
NODE_ENV=development
TWILIO_ACCOUNT_SID=your_twilio_sid
TWILIO_AUTH_TOKEN=your_twilio_token
```

### 3. تشغيل الخادم

```bash
npm start
```

الخادم سيعمل على: `http://localhost:5000`

### 4. تشغيل لوحة الإدارة

```bash
cd admin-dashboard
npm install
npm start
```

لوحة الإدارة: `http://localhost:3000`

### 5. بناء التطبيق الموبايل

```bash
cd mobile-app

# للـ Android
npx react-native run-android

# للـ iOS
npx react-native run-ios
```
